// ══════════════════════════════════════════════════════════════════
// HOW THE FULL NOTIFICATION FLOW WORKS
// ══════════════════════════════════════════════════════════════════

/*
TENANT SUBMITS MAINTENANCE:
1. NewRequestActivity → calls FirebaseHelper.submitMaintenanceRequest()
2. On success → calls notifyLandlords()
3. Finds all landlords from Firestore
4. For each landlord → saves a document to notifications collection
5. The notification appears when landlord opens NotificationsActivity
6. Push notification sent if landlord has FCM token

LANDLORD ASSIGNS VENDOR:
1. LandlordMaintenanceActivity → taps request → picks vendor
2. Updates maintenanceRequests document with assignedVendor + status = "In Progress"
3. Calls notifyTenantVendorAssigned()
4. Saves document to notifications collection for tenant
5. Calls sendPushToTenant() → shows local notification on device
6. Tenant opens NotificationsActivity → sees "🔧 Vendor assigned..."

LANDLORD MARKS RESOLVED:
1. Taps "Mark as Resolved" in the dialog
2. Updates status in Firestore
3. Saves "✅ Issue resolved" notification for tenant
4. Tenant gets notified

IN-APP NOTIFICATIONS:
- All notifications saved to Firestore: notifications/{id}
- Fields: userId, title, body, type, read, createdAt
- NotificationsActivity loads them for current user
- Unread ones have blue background
- Tapping goes to the relevant screen
- "Clear all" deletes them from Firestore

PUSH NOTIFICATIONS (for real push to work):
- Currently: saves notification to Firestore + logs FCM token
- For real push: go to Firebase Console → Extensions
- Install "Trigger Email" or "Send FCM notifications"
- OR set up a Cloud Function that triggers on
  notifications collection write and sends FCM push
*/
