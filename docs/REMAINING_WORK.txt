STEP 1 — Firebase Console setup (do this once, takes 10 min)
──────────────────────────────────────────────────────────────
1. Go to console.firebase.google.com
2. Create project named "RentEase"
3. Add Android app with package: com.example.rentease
4. Download google-services.json → paste into app/ folder
5. Enable Authentication → Email/Password → Save
6. Enable Firestore → Start in test mode
7. Paste Firestore Security Rules (below)


STEP 2 — Firestore Security Rules
──────────────────────────────────────────────────────────────
Paste in Firebase Console → Firestore → Rules:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
      allow read: if request.auth != null; // landlords can read tenant data
    }
    match /maintenanceRequests/{id} {
      allow read, write: if request.auth != null;
    }
    match /payments/{id} {
      allow read, write: if request.auth != null;
    }
    match /conversations/{convId} {
      allow read, write: if request.auth != null;
      match /messages/{msgId} {
        allow read, write: if request.auth != null;
      }
    }
    match /inviteCodes/{code} {
      allow read, write: if request.auth != null;
    }
    match /adminNotifications/{id} {
      allow write: if request.auth != null;
      allow read: if false; // only admin reads via console
    }
  }
}


STEP 3 — How to test messaging between Tenant and Landlord
──────────────────────────────────────────────────────────────
1. Sign up as Landlord first (no invite code needed)
2. Go to Tenants tab → tap "Invite" → copy the 6-digit code
3. Sign out
4. Sign up as Tenant → enter the invite code
5. Tenant home → tap "Message" quick action → opens landlord chat
6. Landlord → Messages tab → sees the conversation from tenant
7. Both can reply in real time


STEP 4 — How admin email works
──────────────────────────────────────────────────────────────
When a new user signs up, a document is saved to Firestore:
  collection: adminNotifications
  fields: type, userName, userEmail, userRole, message, timestamp

To get these in your email (official.rentease@gmail.com):
  → Go to Firebase Console → Extensions → Install "Trigger Email"
  → Connect it to your Gmail: official.rentease@gmail.com
  → Point it to the adminNotifications collection
  → Every new signup sends you an email automatically


STEP 5 — Push notifications setup
──────────────────────────────────────────────────────────────
FCMService.kt is already coded. To actually send push notifications:
1. Go to Firebase Console → Cloud Messaging
2. Go to Firebase Console → Functions (requires Blaze plan — paid)
   OR use the free alternative:
3. In Firebase Console → Firestore → create a new rule trigger
   using Firebase Extensions → "Send notifications via FCM"
   This sends push notifications when a new message or
   maintenance request is created — no code needed.


STEP 6 — Generate APK for demo
──────────────────────────────────────────────────────────────
1. Build → Generate Signed Bundle/APK
2. Select APK → Next
3. Create new keystore → fill in details → remember password
4. Key alias: rentease_key
5. Select release/debug → Create
6. Find APK in: app/release/ or app/debug/
7. Transfer to real phone via USB cable
8. On phone: Settings → Install unknown apps → allow
9. Install the APK → done!
