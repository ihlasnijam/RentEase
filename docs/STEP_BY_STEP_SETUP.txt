 STEP 1 — FIREBASE FIRESTORE SECURITY RULES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

HOW TO PASTE:
1. Open browser → go to console.firebase.google.com
2. Click your RentEase project
3. In left menu click "Firestore Database"
4. Click the "Rules" tab at the top
5. Delete ALL existing text
6. Paste the rules below
7. Click "Publish" button

RULES TO PASTE:
─────────────────────────────────────────────────────────────────

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    // Users: anyone logged in can read users (for messaging/search)
    // but can only write their own profile
    match /users/{userId} {
      allow read:  if request.auth != null;
      allow write: if request.auth != null && request.auth.uid == userId;
    }

    // Maintenance requests: tenants create their own, all auth users read/update
    match /maintenanceRequests/{id} {
      allow read:   if request.auth != null;
      allow create: if request.auth != null
                    && request.resource.data.tenantId == request.auth.uid;
      allow update: if request.auth != null;
      allow delete: if false;
    }

    // Payments: authenticated users read/write
    match /payments/{id} {
      allow read, write: if request.auth != null;
    }

    // Conversations: only participants can read/write
    match /conversations/{convId} {
      allow read, write: if request.auth != null
        && (resource == null
            || request.auth.uid in resource.data.participants);
      match /messages/{msgId} {
        allow read, write: if request.auth != null;
      }
    }

    // Invite codes: auth users can read to verify, landlords write
    match /inviteCodes/{code} {
      allow read, write: if request.auth != null;
    }

    // Notifications: users can only read their own
    match /notifications/{id} {
      allow create: if request.auth != null;
      allow read, update, delete: if request.auth != null
        && resource.data.userId == request.auth.uid;
    }

    // Documents: authenticated users only
    match /documents/{id} {
      allow read, write: if request.auth != null;
    }

    // OTP codes: allow unauthenticated access (needed before login)
    match /emailOtps/{email} {
      allow read, write: if true;
    }

    // Landlord verifications: landlord writes own, admin reads all
    match /landlordVerifications/{uid} {
      allow read, write: if request.auth != null
        && (request.auth.uid == uid
            || request.auth.token.email == 'official.rentease@gmail.com');
    }

    // Admin notifications: write only (admin reads via console)
    match /adminNotifications/{id} {
      allow write: if request.auth != null;
      allow read:  if request.auth != null
        && request.auth.token.email == 'official.rentease@gmail.com';
    }
  }
}

RULES TO PASTE:

rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {

    // Maintenance images: tenant uploads their own
    match /maintenance_images/{uid}/{fileName} {
      allow read:  if request.auth != null;
      allow write: if request.auth != null && request.auth.uid == uid;
    }

    // Landlord verification documents
    match /verification/{uid}/{fileName} {
      allow read:  if request.auth != null
        && (request.auth.uid == uid
            || request.auth.token.email == 'official.rentease@gmail.com');
      allow write: if request.auth != null && request.auth.uid == uid;
    }

    // Documents uploaded by users
    match /documents/{uid}/{fileName} {
      allow read:  if request.auth != null;
      allow write: if request.auth != null && request.auth.uid == uid;
    }
  }
}

 STEP 8 — PUSH NOTIFICATIONS (Firebase Cloud Functions)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Right now notifications save to Firestore but no real push is sent.
To send real push notifications:

REQUIRES: Firebase Blaze plan (pay as you go — free up to limits)

1. Install Node.js from nodejs.org
2. Open Terminal/Command Prompt
3. Run: npm install -g firebase-tools
4. Run: firebase login
5. Run: firebase init functions (in your project folder)
6. Choose JavaScript
7. Open functions/index.js and paste:

─────────────────────────────────────────────────────────────────
const functions = require("firebase-functions");
const admin     = require("firebase-admin");
admin.initializeApp();

// Trigger when a notification is saved to Firestore
exports.sendPushOnNotification = functions.firestore
  .document("notifications/{notifId}")
  .onCreate(async (snap, context) => {
    const data   = snap.data();
    const userId = data.userId;
    const title  = data.title;
    const body   = data.body;

    // Get user's FCM token
    const userDoc = await admin.firestore()
      .collection("users").doc(userId).get();
    const token   = userDoc.data()?.fcmToken;

    if (!token) return null;

    // Send push notification
    return admin.messaging().send({
      token,
      notification: { title, body },
      data: { type: data.type || "general" }
    });
  });
─────────────────────────────────────────────────────────────────

8. Run: firebase deploy --only functions
9. Done — every notification document now sends a real push
